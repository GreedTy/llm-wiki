# Tokenization

## 한 줄 정의
토큰화는 텍스트를 모델이 처리하는 최소 단위인 토큰으로 나누고, 각 토큰을 정수 ID로 바꾸는 과정입니다.

## 주요 방식
- **BPE(Byte Pair Encoding)**: 자주 함께 나오는 문자 쌍을 반복해서 병합해 어휘를 만듭니다. GPT 계열이 사용합니다.
- **Byte-level BPE**: 바이트 단위에서 시작합니다. 어떤 문자든 표현할 수 있어서 미등록 단어(OOV)가 없습니다.
- **SentencePiece / Unigram**: 공백까지 하나의 문자로 취급합니다. 언어에 독립적이며 Llama, T5 등이 사용합니다.

## 한국어와 토큰
- 영어 위주로 학습된 토크나이저는 한국어를 음절이나 바이트 단위로 잘게 쪼갭니다. 그래서 같은 의미라도 한국어 문장이 더 많은 토큰을 씁니다.
- 토큰이 많으면 비용이 늘고, [[Context Window]]가 빨리 차고, 응답 지연이 커집니다.
- 한국어 서비스의 비용을 추정할 때는 반드시 실제 토크나이저로 샘플 문서를 측정해야 합니다.

## 실무 팁
- API 요금과 한도는 모두 토큰 기준입니다. 입력 토큰과 출력 토큰의 단가가 다른 경우가 많습니다.
- [[Chunking]]에서 청크 크기는 글자 수가 아니라 토큰 수로 맞추는 편이 정확합니다.
- 숫자나 코드, URL은 예상보다 많은 토큰을 차지합니다.
