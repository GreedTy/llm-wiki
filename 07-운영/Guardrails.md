# Guardrails

## 한 줄 정의
가드레일은 LLM 애플리케이션의 입력과 출력을 검사하고 제한해서, 유해한 콘텐츠, 정보 유출, 오남용, 정책 위반을 막는 안전장치입니다.

## 입력 가드레일
- **프롬프트 인젝션 탐지**: "이전 지시를 무시하라" 같은 조작 시도를 걸러냅니다.
- **주제 제한**: 서비스 범위를 벗어난 질문을 정중하게 거절합니다.
- **개인정보(PII) 마스킹**: 주민번호, 카드번호 같은 민감 정보를 모델에 보내기 전에 가립니다.
- **길이·빈도 제한**: 입력 길이 상한과 사용자별 요청 한도(rate limit)를 둡니다. 비용 폭주와 남용을 막습니다.

## 출력 가드레일
- **유해 콘텐츠 필터**: 혐오, 폭력 등 부적절한 표현을 차단합니다.
- **근거 검증**: 답변이 제공된 문서에 근거하는지 확인합니다([[Hallucination]] 방지).
- **형식 검증**: JSON 스키마 등 출력 형식을 검사합니다.
- **민감 정보 유출 방지**: 시스템 프롬프트나 내부 정보가 응답에 노출되지 않게 합니다.

## 구현 선택지
- **관리형**: Amazon Bedrock Guardrails, Azure AI Content Safety.
- **오픈소스**: NeMo Guardrails, Guardrails AI, Llama Guard.
- **직접 구현**: 규칙 기반 필터와 분류 모델을 조합합니다.

## 에이전트에서 특히 중요한 것
[[LLM Agent|에이전트]]는 도구로 실제 행동을 합니다. 그래서 다음이 필요합니다.
- 도구 권한은 최소로 줍니다.
- 되돌릴 수 없는 행동에는 사람의 확인을 받습니다.
- 도구 결과(웹페이지, 문서) 안의 지시문을 따르지 않게 합니다.
