# Tool Calling

## 한 줄 정의
Tool Calling은 모델이 텍스트 대신 "어떤 함수를 어떤 인자로 호출할지"를 구조화된 형식(JSON)으로 출력하고, 애플리케이션이 그 함수를 실행해 결과를 다시 모델에 돌려주는 방식입니다.

## 흐름
1. 개발자가 도구 목록을 정의합니다. 각 도구에는 이름, 설명, JSON Schema 형식의 파라미터가 있습니다.
2. 모델이 질문을 보고 도구 호출이 필요하다고 판단하면 `tool_use` 블록을 출력합니다.
3. 애플리케이션이 해당 함수를 실행하고, 결과를 `tool_result`로 모델에 전달합니다.
4. 모델이 결과를 바탕으로 최종 답을 만들거나, 다른 도구를 추가로 호출합니다.

## 좋은 도구 설계
- **설명이 곧 프롬프트입니다**: 도구가 무엇을 하는지, 언제 써야 하는지, 언제 쓰면 안 되는지를 구체적으로 적습니다.
- **입력은 단순하게**: 파라미터 수를 줄이고 enum으로 선택지를 제한합니다.
- **출력은 간결하게**: 모델에 필요한 정보만 돌려줍니다. 너무 큰 결과는 [[Context Window]]를 낭비합니다.
- **에러도 정보입니다**: 실패하면 원인과 다음 행동 힌트를 텍스트로 돌려줍니다. 그래야 모델이 스스로 복구할 수 있습니다.

## 제공자별 차이
Anthropic, OpenAI, Amazon Bedrock Converse API 모두 도구 호출을 지원하지만 메시지 형식이 조금씩 다릅니다. [[LangChain]]의 `bind_tools`나 `create_agent`는 이 차이를 추상화해 줍니다. 도구 정의를 여러 앱에서 재사용하려면 [[MCP]]를 씁니다.
