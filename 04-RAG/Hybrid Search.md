# Hybrid Search

## 한 줄 정의
하이브리드 검색은 키워드 기반 검색(BM25 등)과 벡터 기반 의미 검색을 함께 수행하고 결과를 합쳐서, 두 방식의 약점을 서로 보완하는 검색 방식입니다.

## 왜 필요한가
- **벡터 검색**은 "환불 절차"와 "반품 방법"처럼 표현은 달라도 뜻이 같은 문장을 잘 찾습니다. 하지만 에러 코드, 제품명, 고유명사처럼 정확히 일치해야 하는 검색에는 약합니다.
- **키워드 검색**은 정확한 용어 매칭에 강하지만 동의어나 다른 표현에는 약합니다.

## 결과 병합
- **RRF(Reciprocal Rank Fusion)**: 각 검색 결과의 순위 r에 대해 `1/(k + r)`을 더해 최종 점수를 냅니다(k는 보통 60). 점수의 스케일이 달라도 쓸 수 있어 가장 많이 씁니다.
- **가중 합**: 두 점수를 정규화한 뒤 α와 1-α 가중치로 섞습니다.

## 한국어 키워드 검색 주의점
한국어는 조사와 어미 때문에 공백 단위 토큰화로는 매칭이 잘 안 됩니다. 형태소 분석기(Nori, Mecab)나 n-gram 인덱스를 써야 합니다. PostgreSQL의 기본 `english` 텍스트 검색 설정은 한국어에 적합하지 않습니다.
