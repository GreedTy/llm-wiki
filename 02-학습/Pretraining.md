# Pretraining

## 한 줄 정의
사전학습은 웹 문서, 책, 코드 같은 대규모 텍스트로 "다음 토큰 예측"을 학습시켜, 모델이 언어와 세계 지식의 일반적 패턴을 익히게 하는 단계입니다.

## 핵심 내용
- **목표 함수**: 이전 토큰들이 주어졌을 때 다음 토큰의 확률을 최대화합니다(교차 엔트로피 손실). 정답 라벨이 따로 필요 없는 자기지도 학습입니다.
- **데이터**: 수조 개 토큰 규모입니다. 품질 필터링, 중복 제거, 유해 콘텐츠 제거가 모델 품질을 크게 좌우합니다.
- **스케일링 법칙**: 모델 크기, 데이터 양, 계산량을 함께 늘리면 손실이 예측 가능하게 줄어듭니다. Chinchilla 연구는 파라미터당 약 20토큰이 계산 효율적인 비율이라고 제시했습니다.

## 결과물: Base Model
사전학습만 한 모델은 지시를 따르기보다 문서를 이어 쓰는 데 익숙합니다. 그래서 대화형 서비스를 만들려면 [[Fine-tuning|지시 튜닝]]과 [[RLHF]] 같은 사후 학습이 필요합니다.

## 지식 컷오프
사전학습 데이터를 수집한 시점 이후의 정보는 모델이 알지 못합니다. 최신 정보나 사내 문서처럼 비공개 지식은 [[RAG]]로 보완합니다.
