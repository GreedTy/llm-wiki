# Fine-tuning

## 한 줄 정의
파인튜닝은 사전학습된 모델을 특정 작업, 도메인, 응답 스타일에 맞추기 위해 작은 데이터셋으로 추가 학습하는 것입니다.

## 종류
- **SFT(Supervised Fine-Tuning)**: (지시, 모범 답변) 쌍으로 학습합니다. Base 모델을 대화형 모델로 바꾸는 첫 단계입니다.
- **도메인 적응**: 의료, 법률, 사내 용어처럼 특정 도메인의 말투와 형식을 학습시킵니다.
- **Full fine-tuning vs PEFT**: 모든 가중치를 업데이트할 수도 있고, [[LoRA]]처럼 일부만 학습할 수도 있습니다.

## RAG와 파인튜닝, 언제 무엇을 쓰나
| 상황 | 추천 |
|---|---|
| 자주 바뀌는 지식, 출처 제시가 필요함 | [[RAG]] |
| 출력 형식이나 톤, 특정 작업 패턴을 고정해야 함 | 파인튜닝 |
| 작은 모델로 비용을 줄이고 싶음 | 파인튜닝(증류) |
| 둘 다 필요함 | 파인튜닝한 모델에 RAG를 붙임 |

파인튜닝은 새로운 사실을 주입하는 데 비효율적이고 [[Hallucination|환각]]을 늘릴 수도 있습니다. 지식은 RAG로, 행동 패턴은 파인튜닝으로 다루는 것이 일반적인 원칙입니다.

## 실무 팁
- 데이터 품질이 양보다 중요합니다. 수백에서 수천 개의 고품질 예시로도 효과가 납니다.
- 학습 전에 평가셋을 먼저 만들어 두어야 개선 여부를 판단할 수 있습니다.
- 특정 작업에 과하게 맞추면 일반 능력이 떨어지는 파국적 망각(catastrophic forgetting)이 생길 수 있습니다.
